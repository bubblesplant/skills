# 组件复用

- 开始新增或修改页面、布局或前端组件前，先检查是否已有可复用组件，并识别页面结构中可复用的展示或交互，再根据全部引用方的实际范围确定组件归属。
- 供整个前端作用范围复用的组件统一放在 `{{GLOBAL_COMPONENTS_DIR}}`。该目录优先放置跨页面、低业务耦合且接口稳定的通用组件。
- 只在局部范围复用的组件放在所有引用方最近公共祖先目录下的 `components` 中。组件新增了该目录之外的引用方时，须重新计算最近公共祖先，将组件移动到新公共范围对应的 `components`，并同步更新引用；复用范围扩展到整个前端作用范围时，移动到 `{{GLOBAL_COMPONENTS_DIR}}`。
- 在 React 组件函数内声明的子组件须移到函数外或相应的 `components` 目录；需要父组件的数据或回调时，通过 props 显式传入。
