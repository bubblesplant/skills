# 样式方案与命名

- 新增或修改 Vue / React 样式前，先检查当前项目或包的依赖、构建配置和现有组件用法，确认实际启用的样式方案；不能仅凭安装了某个依赖就判定其可用。monorepo 中按当前前端包分别判断。

## Vue

- 已启用 UnoCSS、Tailwind CSS 等原子化 CSS 方案时，优先使用该方案编写样式，并沿用已有配置和写法；原子类难以表达的样式可补充在组件的 scoped 样式中。
- 没有原子化 CSS 方案时，优先在单文件组件中使用 `<style lang="xxx" scoped></style>`。`lang` 使用项目已支持的样式语言，例如 `scss`、`less`；未配置预处理器时使用 `lang="css"`，不为套用示例新增预处理依赖。

## React

- 已启用 CSS-in-JS 方案（如 Emotion、styled-components）时，优先沿用当前作用范围内的方案及其组件、主题和样式写法。
- 没有 CSS-in-JS 方案时，优先使用 CSS Modules，将样式放在 `*.module.css` 中；项目已有预处理支持时可使用对应的 `*.module.scss`、`*.module.less` 等文件。

## BEM 命名

- Vue 和 React 中手写的样式类名统一采用 BEM：块名使用小写短横线，元素使用 `block__element`，修饰符使用 `block--modifier` 或 `block__element--modifier`，例如 `user-card`、`user-card__title`、`user-card--compact`。
- CSS Modules 的源类名同样使用 BEM，通过 `styles['user-card__title']` 等方式引用。CSS-in-JS 中需要手写类名或类选择器时也使用 BEM；原子化 CSS 的工具类和 CSS Modules、CSS-in-JS 自动生成的类名沿用工具输出。
