# 前端公共能力索引

- 按项目实际结构识别可复用的前端公共能力，包括组件、工具方法、Hooks / composables、公共类型、状态管理等，不限于固定目录名。索引放在能力实际所属的共享范围内；局部共享能力不提升到全局索引。
- 查找、复用或新增公共能力前，先从当前作用范围的入口 `AGENTS.md` 查阅相关分类索引，再按任务读取命中能力目录中的必要代码和已有说明。没有索引时按任务定位相关实现，不把缺少索引视为没有可复用能力。不要预先加载所有分类索引、使用文档或整个目录的源码。
- 新增或抽取公共能力时，必须同步维护两层索引：所属共享范围入口的 `AGENTS.md` 概括已有能力并链接分类索引；分类目录的 `AGENTS.md` 逐项记录能力名称、使用场景和目录路径。只为实际存在的能力建立索引，不创建空分类或虚构条目。
- 分类索引中的能力路径使用相对于该 `AGENTS.md` 的真实目录链接，只需指向目录；不要求为每个组件、方法或 Hook 另建 `AGENTS.md`、`README.md` 或详细使用文档。能力没有独立目录时指向其实际所属目录，不为索引拆分或搬动源码；同目录下职责相关的简单方法、类型或常量可以合并一项。
- 公共能力的用途、复用范围或路径发生变化，以及移动、重命名或删除能力时，必须同步更新受影响的分类索引和上层入口，移除失效条目。沿用已有索引位置并合并条目，不重复追加章节，也不覆盖无关约定。

例如，前端入口 `AGENTS.md` 中可以写：

```markdown
- 上传、下载、选择器：参见 [公共组件索引](src/components/AGENTS.md)。
- 日期格式化、文件处理：参见 [公共工具索引](src/utils/AGENTS.md)。
```

对应的 `src/components/AGENTS.md` 只保留简短索引：

```markdown
| 能力 | 使用场景 | 目录 |
| --- | --- | --- |
| Upload | 上传图片或附件，限制文件类型和大小 | [Upload](./Upload/) |
| Download | 下载附件或导出文件 | [Download](./Download/) |
| UserSelect | 表单中搜索并选择用户 | [UserSelect](./UserSelect/) |
```

示例中的能力、场景和目录均须根据实际代码确认；其他类别沿用同样的索引方式。
