# React 手动记忆化

本规则仅适用于未启用 React Compiler 的 React 代码。

- 默认不使用 `memo`、`React.memo`、`useMemo` 或 `useCallback` 做预防性优化。普通的值或函数重建、普通的组件重渲染，以及“以后可能更快”都不是添加理由。
- 事件监听或订阅的绑定与解绑必须使用同一函数引用时，优先在同一个 `useEffect` 内声明处理函数并成对注册、清理；这种写法本身不需要 `useCallback`。只有处理函数必须跨渲染或跨多个调用位置保持同一引用时，才使用 `useCallback`。
- 仅为了稳定传给子组件的回调或对象而使用 `useCallback`、`useMemo` 时，接收方必须确实使用 `memo` 等引用相等机制，并且稳定引用能避免已确认的无效渲染；接收方未做记忆化时不要添加。
- `useMemo` 只用于已确认成本较高的纯计算，或为实际使用 `memo` 的子组件稳定对象属性且收益明确的场景；不要缓存简单表达式、普通字符串拼接或廉价数组处理。
- `memo` 只用于经常以相同 props 重渲染且渲染成本确实有影响的组件。props 每次都会变化或渲染成本很低时不要使用，也不要批量包裹组件。
- 无法明确说明引用稳定要求或实际性能收益时，保持直接实现，不添加手动记忆化。
