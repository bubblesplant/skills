## 目录说明

- 修改文件前，须从文件所在目录逐级向上查找并阅读相关的 `AGENTS.md`（如存在），并遵循其中的说明。
- 对允许自由组织的业务文件，当同一目录混放多个功能、且其中某个功能包含两个或以上文件时，必须将该功能的文件归入对应子目录；框架、工具或公开接口约定的固定路径除外。仅同步规则时，不据此搬动现有业务文件。

## 按需规则

根据当前任务匹配下表，在执行相关操作前读取对应规则；命中多项时分别读取。不要预先加载整个 `.agents/rules/` 目录；任务范围变化时补读新命中的规则。

| 适用条件                                                       | 规则文件                              |
| -------------------------------------------------------------- | ------------------------------------- |
| 新增、修改或重构代码                                           | [代码设计](.agents/rules/代码设计.md) |
| 定义或调整共用的接口类型、返回类型，或新增、修改、抽取公用方法 | [共享代码](.agents/rules/共享代码.md) |
